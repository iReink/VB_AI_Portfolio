# Вадим Баранов — AI-инструменты и автоматизация

[Открыть портфолио](https://ireink.github.io/VB_AI_Portfolio/) · [Написать автору](https://t.me/iReink)

Русскоязычное портфолио для отклика на роль AI-инженера в Goulash. Показывает связь между пониманием бизнес-процессов, продуктовым дизайном и практикой создания AI-инструментов.

Главный кейс — Telegram-помощник с RAG и text-to-SQL. Ещё шесть кейсов раскрывают автоматизацию ежедневных задач, применение LLM, мобильное взаимодействие, игровой эксперимент и коммерческий продуктовый опыт.

## Запуск

Нужен Node.js **22.12+**; CI использует Node.js 24. Зависимости зафиксированы в package-lock.json.

    npm ci
    npm run dev

Сайт: http://127.0.0.1:5173/VB_AI_Portfolio/.

| Команда              | Назначение                    |
| -------------------- | ----------------------------- |
| npm run typecheck    | Проверка TypeScript           |
| npm run lint         | ESLint                        |
| npm run format:check | Проверка Prettier             |
| npm run format       | Форматирование исходников     |
| npm run build        | Production-сборка в dist/     |
| npm run preview      | Предпросмотр собранного сайта |
| npm run test:e2e     | Браузерные проверки           |

Браузерные проверки запускаются на production-сборке:

    npm run build
    npx playwright install chromium
    npm run test:e2e

На Linux для установки системных зависимостей браузера: npx playwright install --with-deps chromium.

## Устройство

- **Vite + TypeScript + CSS**, без UI-фреймворка, серверной части, CMS, аналитики и запросов к AI-сервисам.
- index.html содержит всю главную страницу и тексты семи кейсов. Содержание доступно до загрузки JavaScript и удобно для проверки.
- src/main.ts управляет темой и модальными кейсами. URL-фрагменты поддерживают прямые ссылки и историю браузера. Статья перемещается в диалог без дублирования DOM.
- src/style.css содержит дизайн-токены, обе темы, типографику и адаптивные состояния. Контент не скрывается до выполнения анимаций.
- Изображения и шрифты размещены локально в public/. Все изображения имеют размеры и альтернативные описания. Увеличенные изображения открываются отдельной ссылкой.

Без JavaScript тексты кейсов остаются доступны через стандартные HTML-элементы details. Для них не требуется маршрутизация на сервере. При наличии JavaScript используется нативный dialog с удержанием фокуса, Escape, закрытием по фону и возвратом фокуса.

Настройка темы хранится только в браузере под ключом portfolio-theme. При первом посещении применяется системная тема; её изменения отслеживаются, пока пользователь не выбрал явный вариант. При блокировке хранилища сайт продолжает работать.

## Обновление материалов

Тексты редактируются в index.html: карточка с атрибутом data-case ссылается на соответствующий details с ID case-…. Внутри него находится статья .case-body с коротким названием в data-title.

После добавления кейса нужно обновить количество и сценарии в браузерных тестах. Новые иллюстрации кладутся в public/images/ с осмысленными именами, размерами и alt-текстом. Ссылки увеличения имеют префикс /VB_AI_Portfolio/; src изображений и пути CSS обрабатывает Vite.

scripts/prepare-images.mjs — вспомогательный одноразовый импорт исходных вложений автора. Он не запускается при сборке: оптимизированные изображения уже находятся в репозитории.

## Проверки и публикация

Workflow **Verify and publish portfolio** проверяет типы, lint, форматирование, сборку и браузерные сценарии. Проверки запускаются для pull request. Успешный push в main публикует dist/ на GitHub Pages.

В Settings → Pages источником должен быть **GitHub Actions**. Отдельная ветка gh-pages, токен в коде и пользовательские secrets не нужны. Разрешения pages: write и id-token: write выделены только задаче публикации; сторонние actions закреплены по SHA.

Базовый путь /VB_AI_Portfolio/ задан в Vite. При переносе на другой адрес нужно согласованно обновить base, canonical, Open Graph, sitemap и ссылки полноразмерных изображений.
